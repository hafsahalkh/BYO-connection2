# User Input Archive

Store raw planning inputs here so future sessions can inspect the original
request instead of relying only on summaries.

Suggested file pattern:

- `YYYY-MM-DDTHH-mm-ssZ-initial-prompt.md`
- `YYYY-MM-DDTHH-mm-ssZ-clarification-01.md`
- `YYYY-MM-DDTHH-mm-ssZ-spec-upload.md`

Each file should keep the source text as-is when possible, plus only the minimum
metadata needed to understand where it came from.
